# 의사결정 기록과 실행 순서

2026-10-17 사용자 합의와 실행 상태를 정리한 색인이다. 최초 요청의 FE 자료 세 문서(`BE_REQUIREMENTS.md`, `FE_BE_API_GAP.md`, `FEATURE_BACKLOG.md`)는 검토 자료이며, 미정 정책을 확정하는 근거로 사용하지 않는다. 업무 정책은 [도메인](domain-model.md), HTTP 계약은 [API 명세](api-endpoints.md), 저장 구조는 [ERD](erd.md)를 기준으로 한다.

## 작업 원칙과 단계

- 사용자 요청으로 **FE는 일체 수정하지 않는다**. BE 구현·HTTP 검증과 FE 화면 반영을 구분한다.
- 애매한 항목은 질문과 구현 영향을 먼저 기록한다. 결정 결과의 빈칸은 미정이며, 승인이나 기본값을 뜻하지 않는다.
- 합의 → 기준 문서 반영 → 구현 → 완료 조건 검증 → 기능·정책 단위 커밋·develop push 순서로 실행한다. main 반영·릴리스는 별도 요청 대상이다.
- 완료된 1단계는 기존 API 연동과 실제 42 로그인이다. 사용자가 브라우저에서 홈 복귀·새로고침 로그인 유지·로그아웃 후 새로고침을 확인했다. [검증 기록](fe-integration-stage1-verification.md)을 따른다.
- 2단계 상세 응답과 3단계 ADMIN 통합은 채택 범위의 BE 검증을 마쳤다. 4단계는 후보별 진행 중이며 일부 완료를 전체 완료로 표시하지 않는다. [전체 계획](fe-integration-plan.md)을 따른다.

## 상세 조회 결정

각 행은 2026-10-17 사용자 합의다. [2단계 기록](fe-integration-stage2-review.md)에 요청 대조와 검증 결과를 남겼다.

| ID | 결정 | 실행 상태·영향 |
| --- | --- | --- |
| DETAIL-01 | 회원 수는 ACTIVE 부원과 현재 회장의 고유 사용자 합집합. 회장은 부원 관계가 없거나 LEFT여도 포함하고 겸직은 한 번만 집계. ARCHIVED도 동일, 실제 0명은 0 | BE 검증 완료. 부원 가입·명단 권한을 자동 부여하지 않음 |
| DETAIL-02 | 현재 회장 모두의 intraLogin·displayName 공개, 없으면 []. 내부 ID·이메일·전역 역할 미공개 | BE 검증 완료. 회장 지정·회수와 다음 로그인에서 동기화된 표시 정보 반영 |
| DETAIL-03 | 공개 연락처를 제공하지 않음 | 미도입 확정. 입력 API·응답·컬럼 추가 없음 |
| DETAIL-04 | 해당 동아리에서 가장 최근 시작한 미삭제 활동 1개. 미래 활동·소모임 제외, 동률은 ID 내림차순, 없으면 null. 제목·개최 시각·신청 확정/출석 확인 인원 제공, 개인 명단 미공개 | BE 검증 완료(`4322e15`). 활동 목록·상세에도 출석 인원 제공 |

신청 확정 인원은 CONFIRMED 전체, 출석 확인 인원은 CONFIRMED이면서 PRESENT인 사용자다. 주최자도 같은 기준으로 포함한다. 차이는 출석 미확인 인원이며 결석이 아니다. 누적 출석 점수나 `/me` 최근 참여 집계를 추가한 결정이 아니다. FE 화면 표시 연결은 미완료로 유지한다.

## 역할·관계 결정

각 행은 2026-10-17 사용자 합의다. BE 구현·검증은 `58f828d`, 세부 허용/거절·이관 결과는 [3단계 기록](fe-integration-stage3-review.md)을 따른다.

| ID | 결정 | 실행 상태·영향 |
| --- | --- | --- |
| AUTHZ-01 | SUPER_ADMIN 폐지, USER/ADMIN으로 통합. 최초 ADMIN은 DB에서 지정 | BE 검증 완료. V11로 기존 SUPER_ADMIN을 같은 사용자의 ADMIN으로 전환 |
| AUTHZ-02 | 모든 ADMIN이 사용자 검색·역할 확인과 동아리 회장 지정·회수를 담당. 복수 회장·회장 없음 허용 | BE 검증 완료. 회장은 전역 역할이 아닌 ClubManager 관계이며 부원 가입과 독립 |
| AUTHZ-03 | ADMIN이 다른 ADMIN을 부여·회수. 본인 회수 허용, 마지막 ADMIN은 보호 | BE 검증 완료. 동시 회수에도 최소 한 명 유지, 마지막 ADMIN 회수 409 |

ADMIN은 활동 작성의 회장 관계, 참가 명단·출결 관리의 주최자 조건, 부원 명단 조회의 ACTIVE 부원 관계를 우회하지 않는다. 기존 세션도 다음 요청에서 현재 역할·관계를 검사한다. FE의 기존 SUPER_ADMIN 전용 화면은 별도 인계 사항이다.

각 행은 2026-10-17 사용자 합의다. 논의 지점과 사전 완료 조건은 [4단계 기록](fe-integration-stage4-review.md)을 따른다.

| EXT-01 | 소모임 전용 공지 불필요. BE에서 도입하지 않고 FE도 소모임 공지를 조회하지 않기로 합의 | 미도입 확정(`4478753`). 공지는 동아리/전체 운영 공지만 유지 |
| EXT-02 | 동아리 활동 생성 시 외부인 참가 허용 여부를 필수 선택. 생성 후 변경 불가 | BE 검증 완료(`297b183`). allowExternalParticipants 필수, 수정 경로 없음 |
| EXT-02 자격 | 외부인 불허 시 주최자를 포함해 ACTIVE 부원만 참가. ADMIN·회장 관계만으로 우회하지 않음 | 생성·신규 참가·취소 후 재신청에서 검사. 부원 자격 상실 시 기존 확정 참가·출결 유지 |
| EXT-02 기존 데이터 | DB가 비어 있다는 사용자 답변에 따라 기존 활동·이전 요청의 호환 보정 미도입 | V13은 활동 테이블이 비어 있어야 적용 가능. 기본값·자동 보정 없음, FE 필드 생략 시 400 |
| EXT-04-A | 동아리 이름은 ADMIN, ACTIVE 요약·소개는 ADMIN 또는 현재 회장. ARCHIVED는 ADMIN만 세 필드 수정 | BE 검증 완료(`28e2b0a`). PATCH에서 보낸 항목만 변경, 이름 포함 회장 요청은 전체 거절 |
| DELETE-01 | ACTIVE 동아리 공지는 현재 회장 또는 ADMIN, 운영 공지는 ADMIN이 삭제. 최초 작성자 여부와 독립 | EXT-05 BE 검증 완료. 다른 동아리 회장·권한 회수된 작성자는 삭제 불가 |
| DELETE-02 | DB 행·본문·작성자 보존, deleted_at으로 삭제. 목록 제외·상세 404, 복원·자동 영구 삭제 미제공. 권한 있는 반복 삭제 204, 처음부터 없는 대상 404 | EXT-05 BE 검증 완료. 보존 기간은 미정 유지, 반복 요청도 현재 권한 검사 |
| DELETE-03 | ARCHIVED 동아리 공지는 ADMIN만 삭제 | EXT-05 BE 검증 완료. 회장만으로는 거절, 운영 공지는 동아리 상태와 무관 |

EXT-04-A의 PATCH 입력 검증·동시 변경 처리 같은 HTTP 세부사항은 [기본정보 수정 계약](api-endpoints.md#동아리-기본정보-수정--구현-계약)에 기록했다. 삭제의 정확한 경로·상태 코드와 검증 증거도 API·4단계 기록에 동기화했다.
